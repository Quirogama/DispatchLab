# Security policy

## Supported versions

Only the latest version on the `main` branch is actively maintained.

## Reporting a vulnerability

Please do not report security vulnerabilities in public issues. Use GitHub's
private vulnerability reporting for this repository when available. Include
the affected endpoint or file, reproduction steps, expected impact, and any
safe mitigation you identified.

The public demo is intentionally anonymous for fast evaluation. Do not use it
with personal data, production credentials, or sensitive experiment data.
